2. Select folder with answer files
3. Click "Upload & Process"
4. See: Scores + Matched/Missing concepts per file

## How It Works (Simple Version)

```
Student Answer → Find similar model chunks → LLM scores → Save results
```

**Why?** Prevents hallucination. LLM only sees what's in model answer.

## What's Actually Happening

### When You Batch Upload:

```
You: Upload 5 answer files
         ↓
Backend: For each file
         ├─ Extract text from PDF/TXT/JSON
         ├─ Convert to vector (embedding)
         ├─ Find similar chunks from model answer
         ├─ LLM compares (with context only)
         ├─ Get score + concepts
         └─ Save to database
         ↓
Frontend: Display results
         ├─ Per-file: Score 85/100, Matched: [...], Missing: [...]
         ├─ Per-file: Score 72/100, Matched: [...], Missing: [...]
         ├─ Per-file: Score 91/100, Matched: [...], Missing: [...]
         └─ Summary: Avg 82.7, Range 72-91, Time 8.3s
```

**Why this works:**
- No hallucination (LLM only sees model chunks)
- Consistent scoring (temperature=0)
- Transparent feedback (see matched concepts)

## Technical Details

**Processing Pipeline (per file):**
1. Extract text from file
2. Generate embedding
3. Query vector DB for similar model answer chunks
4. LLM evaluates with retrieved context only
5. Parse JSON output
6. Save to MongoDB
7. Display results

**Why this works:**
- No hallucination: LLM only sees model answer context
- Consistent scoring: temperature=0
- Transparent: See matched/missing concepts
- Scalable: Process 100s of files

## Performance

┌─ HOW BATCH UPLOAD WORKS ──────────────────────────────────────────────┐
│                                                                        │
│  You select folder:                                                   │
│    ~/answers/                                                         │

│    └─ student3.json                                                   │

│                                                                        │
│    File 1: student1.pdf                                               │
│      1. Extract text ────────────────────────────────────────────    │
│      2. Generate embedding ────────────────────────────────────────  │
│      3. Query vector DB ───────────────────────────────────────────  │

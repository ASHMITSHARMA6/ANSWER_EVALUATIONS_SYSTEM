## Batch Upload (NEW FEATURE)

1. Dashboard → **Batch Upload**
2. Select folder with answer files (PDF/TXT/JSON)
3. Click "Upload & Process"
4. System evaluates each file:
   - Extracts text
   - Finds similar model answer chunks
   - LLM scores with context only
   - Saves: Score + Matched concepts + Missing concepts + Feedback

**Result:**
```
File: student1.pdf
Score: 85/100
✓ Matched: [concept1, concept2]
✗ Missing: [concept3]
Feedback: "Good understanding but..."

File: student2.pdf
Score: 72/100
... (same format)

Summary:
Average: 78.5/100
Range: 72-85
Time: 4.2s
```

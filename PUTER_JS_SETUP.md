# 🚀 Puter.js AI Setup Guide

## What is Puter.js?

Puter.js is a **simple, free AI API** that provides:
- ✅ Easy text generation
- ✅ No complex authentication
- ✅ Free tier available
- ✅ Quick setup

---

## Step 1: Get Puter.js API Key

### Option A: Free Tier (Recommended)
1. Go to: https://puter.com
2. Sign up with your email
3. Go to **Settings** → **API Keys**
4. Create a new API key
5. Copy the key (starts with `ptr_` or similar)

### Option B: Using Public Endpoint
Puter.js has public endpoints that might not require authentication:
- Check: https://api.puter.com/docs

---

## Step 2: Update Your Environment

Edit `/home/ansh/Desktop/TES/backend/.env`:

```properties
# Puter.js AI API
PUTER_API_KEY=your_puter_api_key_here
```

Example:
```properties
PUTER_API_KEY=ptr_abc123xyz789
```

---

## Step 3: Restart Backend

```bash
pkill -9 node
cd /home/ansh/Desktop/TES/backend
node src/index.js
```

---

## How It Works

The app will now:

1. **Try Puter.js first** (if API key provided)
   - Fast response
   - Simple integration
   - Reliable

2. **Fall back to Hugging Face** (if Puter fails)
   - Alternative AI source

3. **Use local generator** (if both APIs fail)
   - Instant questions
   - No API dependency
   - Still good quality

---

## Testing Puter.js

Run this command to test:

```bash
curl -X POST https://api.puter.com/v1/ai/text/generate \
  -H "Authorization: Bearer YOUR_PUTER_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Hello world","max_tokens":100}' 2>&1
```

## Alternative: Use Free AI Services

If Puter.js doesn't work, here are free alternatives:

### 1. **OpenAI API** (if you have credits)
- Get key: https://platform.openai.com/api-keys
- Better quality but paid after trial

### 2. **Replicate API** (Free tier available)
- Get key: https://replicate.com/api
- No credit card required for free tier

### 3. **Local AI (Ollama)**
- Run models locally on your machine
- No API key needed
- Slower but completely free

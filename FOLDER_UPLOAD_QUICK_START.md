# 🚀 QUICK START - FOLDER UPLOAD FEATURE

## ⚡ In 30 Seconds

1. **Open Material Tab**
   - Go to: http://localhost:3000
   - Click: "Material" in navigation

2. **Select Upload Folder Mode**
   - Click: "📁 Upload Folder" button

3. **Choose Your Folder**
   - Click: "Choose Files" button
   - Select: A folder with PDF files

4. **Upload**
   - Click: "📤 Upload" button
   - Watch: Progress updates
   - See: "✅ Successfully uploaded X PDFs!"
